# Changelog

Releases up to 1.1.12 list their mod changes in `changelogs/`.

## Unreleased

- The final COD quest asks for 2,000,000 B of each fluid instead of about 2 billion, and 2,048 of each Mechanical Essence instead of 64,738, so it can be completed and its progress shows all the way (#161).
- Servers no longer install Better Advancements, Enchantment Descriptions, Just Zoom, Durability Tooltip and Konkrete, which only players need.

## 1.1.14

- Plutonium pellets take 16 plutonium nuggets instead of 32, and an antimatter pellet takes 16 refined obsidian blocks instead of 32, so both can be automated in a basin.

## 1.1.13

- Polonium pellets take 16 polonium nuggets instead of 32, and a polonium nugget takes 16 fluorite dust instead of 32: a basin fed by funnels or chutes holds at most 16 of one item, so the old recipes couldn't be automated.
