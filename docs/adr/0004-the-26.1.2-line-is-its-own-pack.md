# The 26.1.2 line is its own pack: Mechanical Mastery Reborn

The 26.1.2 line is published as a new pack, Mechanical Mastery Reborn, with its own CurseForge project, slug and tag prefix. It is not another version of Mechanical Mastery Plus, but it stays in this repo beside the older lines. Each line releases with its own tooling.

We had first planned to keep Mechanical Mastery Plus's identity, with a new CurseForge file per Minecraft version. But Reborn is a sequel with its loop reversed (essence first, resources out of it), its own story and a different set of mods. On one CurseForge page, players of 1.19.2 would find a different game under the same name, and updates to either line would look like updates to the other.
