# Recycling is derived from the recipes

The Recycler, the companion mod's tiered machine from a hand-cranked tier up, reads what an item recycles into from the recipes that make it, run backwards. The pack writes only overrides, as `recycling` recipes, and what each essence decomposes into is the pack's alone, in its KubeJS. Reborn is a modpack first, so the mod ships the machine and no recipes of its own.

We could have had the pack write a recycling recipe for every item, as it does for the essences. That would never keep up with the pack's mods: each new mod, and each update to one, would leave its items unrecyclable until someone wrote theirs. Deriving them makes every crafted item recyclable as soon as it is in the pack, and keeps the pack's hand on the few that need another answer.
