# The 26.1.2 line is a skyblock built on the suite, not on Create

The 26.1.2 pack line stays a skyblock, because the skyblock start is what makes a pack Mechanical Mastery, and its tiers are built on the suite (the 5thlayer -works mods) instead of Create. None of the 1.19.2 spine has a 26.1.2 build: Create and its addons, Thermal, Mekanism, Compact Crafting, Industrial Foregoing and Extreme Reactors all stop at 1.21.1 or earlier. The scripting, world-start and quest layers (KubeJS, Lychee, Skyblock Builder, FTB Quests) do have one.

We could have waited for Create to reach 26.1, but Create has no date for it, and the suite is already automation-first, which is the pack's theme. So the 1.19.2 recipe chains and quest book are not ported. Only their shape carries over. If Create reaches 26.1.2 later, it can come in as one branch of the tiers, but the pack doesn't depend on it.
