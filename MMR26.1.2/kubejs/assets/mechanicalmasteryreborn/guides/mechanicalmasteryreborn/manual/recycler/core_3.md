# Core (Tier 3)

<BlockImage id="recycler_core_3" scale="4" p:facing="north" />

A tier-3 [core](core.md). It works as every core does, with fewer turns of its drives per decompose or recycle,
and its Recycler may have up to 3 [floors](index.md#floors).

It is made on a Craftworks Assembler from a [tier-2 core](core_2.md). To upgrade, break the Recycler's core and place
this one where it stood, facing the same way.
