# Core (Tier 3)

<BlockImage id="recycler_core_3" scale="4" p:facing="north" />

A tier-3 [core](core.md). It works as every core does, but a decompose or a recycle takes 4 turns of its
drives, and its Recycler may have up to 3 [floors](index.md#floors). It returns the same yield as any other core.

It is made on a Craftworks Assembler from a [tier-2 core](core_2.md) and pistons and iron bars. To upgrade, break the
Recycler's core and place this one where it stood, facing the same way.
