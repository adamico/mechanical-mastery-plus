# Core (Tier 2)

<BlockImage id="recycler_core_2" scale="4" p:facing="north" />

A tier-2 [core](core.md). It works as every core does, but a decompose or a recycle takes 6 turns of its
drives, and its Recycler may have up to 2 [floors](index.md#floors). It returns the same yield as any other core.

It is made on a Craftworks Assembler from a [tier-1 core](core.md) and iron ingots and smooth stone. To upgrade, break the
Recycler's core and place this one where it stood, facing the same way.
